# One Bullet

There is exactly one bullet in the entire arena, and every character shares it. Whoever is holding it is the only one who can kill. Everyone else — you included, most of the time — is unarmed.

Fire it, and you give up the only thing keeping you alive: the round becomes a fast, dodgeable object again and lands wherever it lands, and now everyone left standing is racing to reach it first.

Five escalating waves. One hit ends you. One hit ends them.

## Play

Open `index.html` in any modern browser — it's a single self-contained file, no build step, no dependencies beyond a Google Fonts stylesheet.

- **Desktop:** WASD/arrow keys to move, mouse to aim, click or space to fire.
- **Touch (phone/tablet):** drag the left half of the screen to move, drag the right half to aim in any direction and fire.

## Deploy

This is a static single-page app. Deploy the repo root as-is on Vercel, Netlify, GitHub Pages, or any static host — no configuration needed.
